# Course website — UI kit
Click-through recreation of a Политех course site, built from the 2025 brand guide (no existing site or code was supplied, so layouts follow the guide's poster/presentation compositions: modular gradient blocks, hairline panel rules, uppercase Onest headings).

Screens (toggle via header nav): **О курсе** (HomeScreen), **Программа** (ProgramScreen, filter tags), **Мои занятия** (LessonScreen, tabs + lesson list), **Записаться** (EnrollDialog → Toast).

Files: `CourseHeader.jsx`, `CourseFooter.jsx`, `HomeScreen.jsx`, `ProgramScreen.jsx`, `LessonScreen.jsx`, `EnrollDialog.jsx`, `data.js` (example course content — replace with the real course).
